# Extract regions

This directory contains the code to extract regions from a FASTA file based on a GFF using AGAT.

## Scripts
The following scripts are found in this directory:
- `command.sh` – a minimal example of an AGAT command to extract regions
- `extract_regions.sh` – a full flexible wrapper to extract specific features

## Data and results
There are some examples of input and output files in the directory.
File names should be self-explanatory.
