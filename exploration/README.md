# Exploration directory

This directory contains files from several exploratory analyses done before the start of the Evo annotation project.

**Warning:** This directory is not fully maintained and documented. Explore at your own risk.

## Directories
This directory contains the following subdirectories:
- `download_genomes` – programmatic download of genomes from the p10k database
- `explore_kmers` – Shiny app for exploring k-mer spectra of genomes
- `extract_kmers` – extraction of k-mer spectra of genomes using Jellyfish
- `get_kmers` – tests of a Nextflow pipeline for automated k-mer extraction and analysis
- `ncbi_datasets_test` – downloading data with the NCBI Datasets CLI
- `protists_local` – testing Jellyfish k-mer extraction on protist genomes
