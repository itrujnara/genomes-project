# Test geneid

This directory contains data for testing geneid with Evo hints.

## Files
This directory contains the following files:
- `evidence.gff` – Evo hints for human HBB
- `gene.fasta` – sequence of human HBB
- `gene_seqs_hint.gff3` – Evo hints for 7 genes
- `Homo_sapiens.9606.param` – geneid parameter file for the human
- `no_hints.gff3` – geneid output for 7 genes with human parameters, without hints
- `with_hints.gff3` – geneid output for 7 genes with human parameters and Evo hints
