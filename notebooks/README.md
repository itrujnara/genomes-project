# Notebooks

This directory contains Jupyter notebooks used in the analysis, as well as some data.

## Directories
This directory contains the following relevant subdirectories:
- `plots` – certain saved plots in PNG format
- `seqs` – sequences of genes used in the annotation analysis
- `tensors` – probability tensors from the analysis in Safetensors format

It also contains the following directories related to exploratory analyses:
- `data` – data for the Hyena notebook
- `hyena-gpt-shakespeare` – model weights from the Hyena notebook
- `wandb` – WandB logs from the Hyena notebook

## Notebooks
This directory contains a number of Jupyter notebooks.
Each contains a brief summary at the top.

One notebook, called `sliding_window`, is provided as a Python script instead, as its outputs are very large.
