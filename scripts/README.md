# Scripts

This directory contains scripts for Evo and Evo 2 inference.

## Files
This directory contains the following scripts:
- `evo_inference.py` – a simple script to run Evo inference on a FASTA sequence
- `evo2_inference.py` –  a simple script to run Evo 2 inference on a FASTA sequence
- `load_evo.py` – a script to test Evo model loading
- `load_evo2.py` – a script to test Evo 2 model loading
- `postprocessor.py` – a script to convert an Evo output to GFF format
- `utils.py` – extra functions used in scripts

All submit scripts (`sbatch`) wrap the Python script with the same name.
